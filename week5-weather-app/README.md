# Week 5 — WeatherNow Application

A responsive weather application built with HTML5, CSS3, and JavaScript that provides real-time weather information using the OpenWeatherMap API.

## Overview

WeatherNow is a production-ready weather application demonstrating API integration, asynchronous programming, and modern frontend development practices. Users can search for weather conditions in any city worldwide with a clean, intuitive interface.

## Key Features

- **City Search** - Quick city lookup with autocomplete support
- **Real-Time Data** - Current weather conditions fetched from OpenWeatherMap API
- **Comprehensive Metrics** - Display of temperature, humidity, wind speed, and pressure
- **Loading States** - Animated loading indicator during data fetching
- **Error Handling** - Detailed error messages for network and validation issues
- **Responsive Design** - Mobile-first approach for all screen sizes
- **Professional UI** - Modern card-based layout with smooth transitions
- **Updated Timestamp** - Shows last update time for weather data

## Weather Information Displayed

- Current temperature and weather condition
- Maximum and minimum temperatures
- Humidity percentage
- Wind speed
- Weather icon representation
- Location city and country
- Last update timestamp

## Technical Implementation

**Architecture**
- Modular JavaScript with clear separation of concerns
- DOM state management for UI synchronization
- Async/await pattern for API calls
- Event-driven user interactions

**Error Handling**
- City not found validation
- API authentication checks
- Rate limiting awareness
- Network error recovery
- User-friendly error messages

**API Integration**
- OpenWeatherMap REST API
- Encoded URI parameters for special characters
- HTTP status code handling
- JSON response parsing

## Technologies

- **HTML5** - Semantic markup and accessibility
- **CSS3** - Flexbox layout, animations, responsive design
- **JavaScript** - Async operations, DOM manipulation, API integration
- **OpenWeatherMap API** - Real-time weather data

## Usage

1. Open `index.html` in a modern web browser
2. Enter a city name in the search box
3. Click Search or press Enter
4. View current weather conditions for the selected city

## Browser Compatibility

Works with all modern browsers supporting ES6+ JavaScript, Fetch API, and CSS3.
